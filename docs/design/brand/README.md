# Brand files

The Two flames logo, chosen by Casey on 17 Nov. `docs/design/brand.md` says what each file is for and where the app serves it.

| File | What it shows |
| --- | --- |
| `logo.png` | The mark, the lockup on light and dark, the app icon, and the mark at sidebar and favicon sizes (2×) |
| `aglowy-mark.svg` | The mark |
| `aglowy-lockup.svg`, `aglowy-lockup-dark.svg` | Mark and wordmark (Mona Sans SemiBold, outlined) |
| `aglowy-app-icon.svg`, `aglowy-app-icon-maskable.svg` | The app icon, rounded and full bleed |
| `icon-512.png`, `icon-192.png`, `apple-touch-icon.png` | The app icon as PNGs, rendered from the full-bleed SVG |
| `favicon-32.png`, `mark-128.png` | The mark as PNGs, transparent |
