# App shell mockup frames

The approved mockup, one PNG per frame, rendered at 2× (desktop 1440 px wide, phone 390 × 844). `docs/design/app-shell.md` says what each frame is and which story builds it.

When you compare your screenshots with these frames, match the layout, the order of things, the spacing rhythm and which parts appear for each role and state. Three things in the frames are placeholders, not targets:

- **Icons** are hand-drawn stand-ins. Build with the Octicons listed in the design doc.
- **Names, dates, studies, goals and notes** are sample data.
- **Colours** approximate Primer's light and dark themes. Use Primer's components and primitives, not the exact pixels.
